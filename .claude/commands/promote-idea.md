Оформи идею «$1» в GitHub issue(s).

1. Делегируй **task-generator**.
2. Он найдёт идею в Notion (Parking lot / Roadmap), прочитает контекст, проверит:
    - нет ли уже похожего issue (`gh issue list --search`),
    - не противоречит ли существующим ADR,
    - нужна ли декомпозиция на несколько issues.
3. Получи черновик(и) issue в стандартном формате (Title / Labels / Этап / Контекст / AC / Технические заметки / Вне scope).
4. Покажи мне черновик(и).
5. Если task-generator сообщил «нужен новый ADR перед реализацией» — НЕ создавай issue, предложи сначала `/design-feature $1`.
6. Если подозрение на дубль — покажи мне номер похожего issue, спроси.
7. По моему «создавай» — `gh issue create` с лейблами. Это `ask`-операция, жди подтверждения.

Не создавай issue автоматически. Не пиши код.
