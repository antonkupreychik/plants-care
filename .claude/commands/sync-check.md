2. Он прочитает Roadmap, Parking lot, Architecture & Decisions в Notion и `gh issue list --state all` + `gh pr list` в GitHub.
3. Получи отчёт в стандартном формате (дрейф / незаведённые / конфликты / висяки / картина по вехам / рекомендации).
4. Покажи отчёт мне **целиком**, без сокращений.
5. Спроси, что делать с находками:
    - Обновить устаревшие статусы в Notion Roadmap (🟠→✅)? — делегируй backlog-analyst закрыть петлю, точечными правками.
    - Промотировать незаведённые задачи в issues? — делегируй `task-generator` по конкретным пунктам.
    - Что-то слить/закрыть как дубль? — покажи мне команды `gh`, выполню сам или подтвержу.

Ничего не меняй в Notion и GitHub без моего явного «да».
